# Astro-React-Portfolio

Personal developer portfolio for **Jesenhower Nachor** — Aspiring Software Engineer & Full-Stack Developer. Built with **Astro 7**, **React 19**, and **Tailwind CSS**.

## 🚀 Tech Stack
- **Framework:** Astro 7 + React 19 Islands
- **Styling:** Tailwind CSS v4
- **Animations:** GSAP
- **Deployment:** Vercel (with enterprise-grade HTTP security headers)

## 🧞 Commands

| Command | Action |
| :--- | :--- |
| `npm install` | Installs project dependencies |
| `npm run dev` | Starts local development server |
| `npm run build` | Builds static production bundle into `./dist/` |
| `npm run preview` | Previews production build locally |
